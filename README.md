# JavaScript Practice Projects 🚀

This is a collection of mini-projects I built from scratch to practice my core JavaScript logic, DOM manipulation, and API fetching before moving on to React and MERN stack development.

* **🔢 Digital Counter:** [View Live App](https://fahimakaz2-afk.github.io/project-JS/counter-app/index.html)
* **🛒 Gadget Store Filter:** [View Live App](https://fahimakaz2-afk.github.io/project-JS//product-filter/index.html)
* **🪙 Live Crypto Tracker:** [View Live App](https://fahimakaz2-afk.github.io/project-JS/Live_Crypto_Price_Tracker/crypto.html)

## 🛠️ Projects Breakdown

* **Digital Counter:** Built to practice DOM selectors, click event listeners, and saving data using `localStorage` so it doesn't reset on a page refresh.
* **Gadget Store Filter:** Built to practice looping over arrays using `.map()` and creating clean sorting features using the `.filter()` method.
* **Live Crypto Tracker:** Built to practice asynchronous programming (`async/await`) by fetching real-time live Bitcoin prices over the internet using a public API.

## 🧠 Why I Built This
To get comfortable writing clean JavaScript logic and to break the loop of forgetting development concepts before diving into advanced full-stack frameworks.
